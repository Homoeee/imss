# 测试说明

## 回归与真实组件

```powershell
python -m unittest discover -s tests -v
```

合成用例覆盖金额规范、字段识别、编号、手工分组、分笔支付、模板和原件保护。test_review_workflow.py 另覆盖金额建议、双向唯一性、多候选和争用、明确匹配优先、Excel 配色排序、链接、确认、公式与缺行校验、改名后重复生成及输出覆盖保护。

test_output_layout.py 覆盖编号附件归入“原始材料”、独立 PDF 位于根目录、旧平铺附件重建迁移、嵌套摘要和补导 PDF、修改保护、同名文件阻止覆盖，以及输出记录路径越界校验。核对后改名测试同时验证旧附件被清理，输入原件保持不变。

`test_forms.py` 覆盖行程表三位乘车人的姓名、缺省留空、姓名与签字图片分开填充、承诺原图字节不变、姓名类型校验，以及 `detail.json` 按 Excel 自动分组命中、逐字段发票号覆盖分组及命令行默认乘车人姓名。Word 修改后还需用真实附件导出 PDF 检查分页和姓名栏，不能只看 XML 测试结果。

test_order_fields.py 使用匿名订单/支付正文覆盖无标签商品标题、跨行价格与数量、规格/店铺/推荐区排除、多商品、实付和优惠区分、多个实付冲突、断裂数字、退款与未付款状态、账单顶部支出、行程费用提示、订单号及发票链接。可独立运行：`python -m unittest discover -s tests -p test_order_fields.py -v`。这些测试检查字段逻辑；并不证明 OCR 能读出图片中的全部文字。

`test_tables.py` 覆盖签到/签领标题与拆行活动名、正文提及表名不误分类、采购明细标题、表格总额列与空列对齐、多商品清单、合计/总额冲突、数量和单价排除、空合计栏汇总必须确认、Word 合并单元格、局部 OCR 必须带总额标签、人员表无需发票独立导出及原 PDF 字节不变。私有清单的缓存及局部 OCR 验证记录在 `.qa/table-real-cached-check.json`，不将文件名中的金额提供给识别器，也不改用户核对状态。

`test_invoice_images.py` 覆盖标题漏字的税务结构分类、订单发票入口反例、透明 PNG 白底、红色表格定位、价税合计局部 OCR 坐标、缺小数点不猜测、逗号小数点提示及乱码品名拦截。私有 PNG 诊断见 `.qa/png-invoices-check.json`；分类、金额提取、品名提取和整组生成分别统计，不将分类通过记为整笔报销成功。

test_integrations.py 使用项目内真实 Tesseract/LibreOffice 验证 OCR 与 PDF 导出；组件不足时明确跳过。test_reference.py 使用本地私有语料验证原件字节、文字 PDF 发票金额与参考材料页数；公开仓库没有私有语料时明确跳过。测试不把答案提供给识别器。

## 私有语料评测

`test_multievidence.py` 覆盖商品营销名称候选、编号与金额冲突、同金额争用、独立证据排序、推断名称不重复计分、TSV 坐标缩放、跨页分离、碎片化付款字段、局部数字 OCR 必须确认/不猜小数点、多组批量确认、候选篡改/失效、与主表修改冲突、缺行程单仍阻止生成、旧 Excel 兼容、重复 build、recheck 保留确认及未确认编辑、Excel 占用时不损坏原表且清理临时文件。候选数不能代替正确率或成功生成数。

```powershell
python tools/benchmark.py prepare "tests/报销材料模板" "tests/fixtures/reimbursement"
python main.py scan "tests/fixtures/reimbursement/input"
python tools/benchmark.py evaluate "tests/fixtures/reimbursement/oracle.json" "tests/fixtures/reimbursement/核对清单/核对清单.json" ".qa/evaluation"
```

固定种子复制原件为随机文件名，部分图片改为 tmp/temp 后缀；oracle.json 仅供外部评分。输入、已核对 CSV、扫描文字和输出包含真实信息，只留本机。生产流程不读取 oracle，不按文件原名猜测商品或金额。

扫描固定输出两个目录，`scan`/`run` 会清空重建已有输出。需要留存实验结果时先保存，或在另一实验父目录放置原件副本。`test_scan_reset.py` 覆盖两目录及嵌套旧文件清理、重复扫描、输入和旁侧目录保护、无效输入/模板不触发删除、输出内模板拦截、同名文件替换、Windows 重解析点预检与占用错误提示；实际符号链接用例在系统缺少创建权限时明确跳过。开发工具产生的诊断文件属于开发实验，不进入用户报销目录。

tools/refresh_scan.py 可在两个固定输出目录为空时，用旧缓存重算识别规则；不会覆盖已有核对结果：

```powershell
python tools/refresh_scan.py "旧缓存/扫描结果.json" --rules-only
```

该工具核验原件摘要；没有 --rules-only 时会重新提取 PDF 文字。旧扫描状态若来源位置已变，须先恢复对应原件，不要跳过摘要校验。
