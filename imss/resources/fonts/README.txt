IMSS Sans SC Regular

Derived from Noto Sans SC 2.04 (Adobe and Google), using the regular
weight (400) of the TrueType variable font. The full character map is
retained. The family was renamed when creating this static instance.
The checked box (U+2611) combines the font's existing square and check mark.
